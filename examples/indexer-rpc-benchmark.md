# Data indexer RPC benchmark

Indexer and analytics workloads depend on block reads, event logs, freshness, and method compatibility.

Important signals include:

- `eth_getLogs` support;
- block-read latency;
- p95 and p99 latency;
- timeout rate;
- latest block freshness.

Run the Data indexer / analytics profile:

https://getblock.io/rpc-benchmark/
